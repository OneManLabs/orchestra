# Security policy

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue or discussion.

Report security concerns privately through the contact channel at <https://www.onemanlabs.org/>. Include the affected component and version, reproduction steps, impact, and any suggested mitigation. Do not include live credentials, recovery tokens, enrollment tokens, or private fleet data unless One Man Labs specifically requests a secure transfer.

One Man Labs will acknowledge the report when practical, investigate it, and coordinate disclosure and remediation based on severity. Please allow a reasonable opportunity to address the issue before public disclosure.

Only the latest version on the repository's default branch is currently supported with security updates.
